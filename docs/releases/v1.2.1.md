# Ciallogcat v1.2.1

## CLI fixes

- Text output defaults to human-readable local timestamps such as `2026-10-28 11:43:20.123+08:00 [received]`. Text display follows the selected `--time-basis received|device`, just like time filtering; host receipt is not mislabeled as device time.
- Add text-only `--time-format readable|epoch|rfc3339` and `--timezone local|utc`. Epoch uses exact integer seconds and the available fractional precision, independent of timezone. Local offsets/DST are resolved for each instant. Missing absolute timestamps, unsupported calendar ranges and timezone fallbacks are explicitly labeled rather than guessed.
- Avoid adding a second newline when a message already ends in LF/CRLF. Internal whitespace, trailing spaces and intentional multiple trailing newlines remain intact. Archives, JSONL, frozen protobuf projection and desktop clipboard formatting are unchanged.
- `stop` now requests cooperative shutdown even when the heartbeat is stale. It waits for worker acknowledgement; a timeout does not prove process death.
- Add `stop --force`: after the cooperative wait, an unacknowledged session can be administratively closed with `state: abandoned`, `reason: administratively_closed` and `worker_exit_confirmed: false`. This does not kill or confirm exit of the worker/ADB, and never signals a persisted PID.
- Administrative closure is immutable, first-writer-wins metadata that preserves the observed published status boundary. New session-based readers honor it despite later old-worker status/log writes; the legacy query path is capped too. Original status, stale lock files, partial tails and logs are not overwritten, deleted or repaired; no footer is fabricated. Hard-link publication failure fails closed.

## Examples

```sh
ciallogcat-cli query-v2 --session-dir ./capture-session --all --format text --timezone utc
ciallogcat-cli query-v2 --file capture.jsonl --all --format text --time-basis device --time-format rfc3339
ciallogcat-cli query-v2 --file capture.jsonl --all --format text --time-format epoch
ciallogcat-cli stop --session-dir ./old-session --force --wait-secs 1
```

A successful administrative close is not capture completeness or process-exit confirmation. Use v1.2.1+ commands with `--session-dir` for the frozen management view; old binaries and direct file readers may not honor it. Old snapshots/references beyond the closed boundary are rejected. A streaming query racing closure can emit partial output before returning an error; require successful exit and completion metadata before trusting the output.

See the [CLI guide](https://github.com/IllyasvielEin/Ciallogcat/blob/v1.2.1/docs/cli.md) for exact timestamp, newline, stop and compatibility semantics.

## Downloads and known limits

The normal release includes Linux x86_64 and Windows x86_64 GUI/CLI archives, separate Ubuntu 24.04 GUI/CLI DEBs, and all six SHA-256 checksums. ADB is installed separately. Publication requires all four build/packaging jobs to succeed.

Existing X27 (desktop non-log placeholders), X28 (inconsistent status sequence bounds in context/get), X29 (deep extension conversion), X11/XIM and real-device/desktop acceptance limitations remain as documented in TODO.md. The new CLI renderer does not change desktop clipboard behavior, and administrative closure does not upgrade archive integrity or capture completeness.
