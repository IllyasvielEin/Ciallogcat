# Ciallogcat CLI v1.3.2

This release publishes **CLI binaries only**. Desktop users should continue to use the [v1.3.0 GUI downloads](https://github.com/IllyasvielEin/Ciallogcat/releases/tag/v1.3.0). The changes address CLI feedback in [#3](https://github.com/IllyasvielEin/Ciallogcat/issues/3).

## Time sources and readable output

- Text queries accept `--display-time received|device|both`, independently of the clock used by `--since`/`--until` filters. Explicit display modes label each clock; omitting the option preserves the previous text layout and clock selection.
- Received time is the persisted host observation, not device event time. Device display uses an exact protobuf epoch when available, otherwise clearly labeled, unconverted device timestamp text or an unavailable marker. Yearless text is never assigned a guessed year or timezone, and displaying it does not make it valid for device time filtering.
- Text summaries describe the requested and effective display policy. Changing presentation does not change record identities, matching rules or cursor validity.

```sh
ciallogcat-cli query --file capture.jsonl --all --format text --display-time both
```

## Capture shutdown

- SIGINT, cooperative stop and the duration limit immediately request ADB termination, then allow up to one second to preserve complete buffered host records within the existing entry and byte budgets. A full writer no longer causes the pending record to be discarded immediately on an intentional stop.
- Admission closes on its deadline, a hard limit or an actual failure. Backend cleanup continues despite writer backpressure; discarded records and incomplete protobuf frames remain explicit. Device-side or unread losses may still be unknown, so this does not guarantee lossless capture.
- Final `shutdown` status separates the original stop trigger, ADB/reader cleanup, host admission result and footer write confirmation. An unconfirmed footer does not prove it is absent. SIGINT retains the `interrupted` envelope and exit code 130 after successful cleanup; actual output or ADB failures retain their own error codes.

## Evidence completeness

Query JSON and text/JSONL stderr summaries include bounded `evidence.summary`, explaining query completion, artifact validation and source capture coverage together. A completed query and finalized artifact can coexist with unknown capture completeness and no reported gaps. An empty gap list is not evidence of lossless capture. Session status observations are distinguished from the fixed snapshot being queried.

## Downloads and compatibility

The release provides a Linux x86_64 CLI tar.gz, Windows x86_64 CLI ZIP and Ubuntu 24.04 amd64 CLI DEB, each with a SHA-256 file (six uploaded assets). ADB is installed separately. Native archive and cursor formats are unchanged; control/query summaries add fields described above. Default text layout and SIGINT exit code 130 remain compatible.

This CLI-only release does not replace the repository's Latest marker. Use the [v1.3.2 release page](https://github.com/IllyasvielEin/Ciallogcat/releases/tag/v1.3.2) for these downloads. The shared Cargo package version is 1.3.2 and GitHub source archives contain the full repository, but this release introduces no GUI feature changes and publishes no GUI binaries.

Local Linux validation covered headless and default-feature tests, strict Clippy, controlled shutdown/backpressure and footer failure/timeout cases. These checks do not establish Android device losslessness or native desktop interaction coverage.
