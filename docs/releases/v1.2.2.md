# Ciallogcat v1.2.2

## CLI query readability fixes

- Every successful `query-v2` page and streaming summary now includes `time_window`, even when no records match. It reports the selected clock, original query anchor, resolved inclusive start and exclusive end. Bounds include UTC RFC3339 text where representable and exact signed nanoseconds as decimal strings; unsupported calendar values remain explicit null text, not guessed dates or panics. Relative bounds keep their existing cursor anchor. An omitted bound remains unbounded; the separate snapshot fence is unchanged. This metadata describes the requested window, not available data coverage or a definitive explanation of zero matches.
- Text process names now use a deterministic maximum of 32 display columns in both terminal and redirected output. A visible middle ellipsis retains useful prefix/suffix information, including long Chromium-style renderer names. Unicode grapheme clusters are preserved and wide characters count by display width. `--process-width N` adjusts the column (1–4096); `--process-width 0` restores the full name. PID/TID and full messages remain intact. The summary reports the width and number of shortened names; an abbreviation is not a unique process identifier.
- Normal default receipt-time text no longer repeats `[received]` on every row. The summary always names the clock. Non-default device time and exceptional missing-time/calendar/timezone labels remain explicit.
- JSONL/get retain full process names. Archive bytes, fixed protobuf projection, GUI clipboard behavior, filtering and cursor bindings are unchanged.

## Examples

```sh
ciallogcat-cli query-v2 --session-dir ./capture-session --all --since 60s --format text
ciallogcat-cli query-v2 --file capture.jsonl --all --format text --process-width 0
ciallogcat-cli query-v2 --file capture.jsonl --all --format text --process-width 48 --time-basis device
```

For a zero-result relative query, inspect stderr summary `time_window.since_inclusive.rfc3339`, `basis` and the scan/completion fields before widening the window. `until_exclusive: null` means no upper time predicate, not the current time. Existing streaming-error semantics remain: partial stdout is possible before a late error, so require successful exit and the final summary.

## Verification and downloads

The fix was checked by full local GUI/headless test suites, Clippy, formatting, release builds, Python fixture/example/benchmark/packaging tests and pinned protobuf regeneration. Native Windows and Linux Checks passed for the implementation commit. Long process names were reproduced with synthetic protobuf fixtures, not represented as real-device acceptance.

The normal release includes Linux x86_64 and Windows x86_64 GUI/CLI archives, separate Ubuntu 24.04 GUI/CLI DEBs, and all six SHA-256 checksums. ADB is installed separately. Publication requires all four build/packaging jobs to succeed.

Existing X27–X29, X11/XIM and real-device/desktop acceptance limitations remain as documented in TODO.md. No previous tags or release assets are replaced.

See the [CLI guide](https://github.com/IllyasvielEin/Ciallogcat/blob/v1.2.2/docs/cli.md) for exact query-window and text presentation contracts.
