# Ciallogcat v1.2.0

## Changes

- Extend `query-v2` with the shared GUI regex/case, Tag include/exclude, package and minimum-level predicates, plus exact PID/TID filters. Literal case-sensitive message matching remains the default.
- Add `--all` to stream every page of a fixed snapshot, including empty matching pages. `--format text` and `--format jsonl` return full decoded records, not truncated previews; completion/cursor metadata goes to stderr. Default JSON preview pagination and existing literal-only cursors remain compatible.
- Add inclusive `--since` and exclusive `--until`, accepting RFC3339 instants or relative ages such as `5m`. Relative bounds remain fixed across cursor pages. The default received-time basis uses host observation; device-time filtering requires the exact protobuf epoch.
- New default v1 captures store optional `observed_unix_ms`, sampled by the ADB adapter before queue/backpressure waiting. Old v1 records remain readable; absent timestamps are reported explicitly rather than assigned a guessed year or timezone. No capture identity is fabricated.
- Raise the default capture/start disk-output cap from 64 MiB to 1 GiB. The 600-second duration and record bounds remain active; no rolling overwrite or whole-capture RAM allocation is introduced.
- Add explicit query completion metadata and regression coverage for sparse scans, stream output, timestamp boundaries, cursor binding, legacy compatibility and v2/v3 decoded projections.
- Fix the Windows release test's platform-dependent assumption that two large context previews always fit an 8192-byte response. The test now requests a small preview while retaining full decoded-retrieval and response-budget assertions.

## Example

```sh
ciallogcat-cli query-v2 --session-dir ./capture-session \
  --all --query 'timeout|failed' --regex --ignore-case \
  --tag Network --pid 1234 --since 5m --format text
```

Filters combine with AND. Tag matching is literal and case-sensitive. Without `--all`, text/JSONL still returns one bounded page; follow the stderr cursor or use `--all`. Check exit status and the final completion summary: a late source or output error may leave partial stdout. Decoded JSONL/text is a derived view, not a lossless native archive. See [CLI usage](https://github.com/IllyasvielEin/Ciallogcat/blob/v1.2.0/docs/cli.md) and [query protocol](https://github.com/IllyasvielEin/Ciallogcat/blob/v1.2.0/docs/agent-query.md).

## Downloads

The normal release includes GUI and standalone CLI packages for Linux x86_64 and Windows x86_64, separate Ubuntu 24.04 GUI/CLI DEBs, and a SHA-256 checksum for each package (six packages plus six checksum files). Install ADB separately. Linux GUI packages require compatible Ubuntu 24.04 libraries and a graphical desktop.

## Known issues and validation limits

- X28: context/get can exceed a reference's published sequence bound when session status contains inconsistent byte and sequence watermarks.
- X29: deeply nested extension data can produce converted or re-filtered documents that cannot be read back due to JSON depth limits.
- X27: desktop non-log event/unparsed rows can display/copy placeholder log fields. New CLI text streaming avoids those placeholders but does not change the desktop issue.
- X11/XIM candidate-window positioning remains unresolved. Real Android/OEM capture, native Windows desktop interactions, Wayland/IME, GPU and multi-display acceptance remain outstanding.

The feature commit passed Linux GUI/headless and native Windows Checks, including Windows tests/Clippy/build/smoke and Linux X11 startup smoke. Local GUI/headless tests, strict Clippy, release builds and packaging tests passed. One early local GUI test failed under concurrent load; isolated and subsequent full runs passed, and no unrelated GUI behavior was changed. Synthetic near-1-GiB no-hit query scans completed with bounded memory; this is not a real-device throughput guarantee.

Publication is gated by all four GUI/CLI Linux/Windows release build and packaging jobs. Existing v1.0/v1.1.0 tags and assets are not replaced. Remaining work is tracked in TODO.md.
