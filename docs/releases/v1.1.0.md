# Ciallogcat v1.1.0

## Changes

- Share capture lifecycle, history scope, session identity, reconnect and bounded resource handling between the desktop app and headless CLI.
- Add bounded Agent evidence queries with snapshot/tail cursors, references, full-message and context retrieval, and Python workflow examples.
- Add native v2/v3 documents and opt-in protobuf capture with preserved source metadata, extensions and explicit gaps; retain text capture as the default.
- Add desktop file loading, saving and filtered export, reading/navigation tools, reference copying and on-demand read-only device diagnostics.
- Expand regression tests, Linux/Windows checks, packaging validation and transport benchmarking tools.

## Downloads

GUI and standalone CLI packages are provided for Linux x86_64 and Windows x86_64, including separate Ubuntu 24.04 DEB packages and SHA-256 checksums. Install ADB separately. Linux GUI packages require compatible system libraries and a graphical desktop.

## Known issues and validation limits

- X28: context/get can exceed a reference's published sequence bound when session status contains inconsistent byte and sequence watermarks.
- X29: deeply nested extension data can produce converted or re-filtered documents that cannot be read back due to JSON depth limits.
- X27: non-log event/unparsed rows can display and copy placeholder log fields (Info, PID/TID 0, tag logcat).
- X11/XIM candidate-window positioning remains unresolved. Android/OEM devices, native Windows desktop interactions, Wayland/IME, GPU and multi-display behavior have not completed acceptance testing.

Existing Linux mock tests and strict Clippy checks pass; these do not establish real-device or desktop acceptance. The release workflow requires all four GUI/CLI Linux/Windows build and packaging jobs to succeed before publication. See TODO.md and docs/validation.md in the source for the remaining work.
