# Ciallogcat CLI v1.3.1

This patch publishes **CLI binaries only**. Desktop users should continue to use the [v1.3.0 GUI downloads](https://github.com/IllyasvielEin/Ciallogcat/releases/tag/v1.3.0).

## Fixes

- Querying an unfinished native file with `--file` now reports the missing `artifact_end` footer, the actual final-record byte offset and the observed record type, instead of misleadingly reporting that the document header lacks `artifact_id` ([#2](https://github.com/IllyasvielEin/Ciallogcat/issues/2)). Malformed final JSON and invalid footers also identify the actual byte offset.
- Missing or malformed final records explain that `--file` requires a finalized artifact and direct active-capture users to `--session-dir`. Ordinary files may also be truncated; the diagnostic does not assume a capture is still running.

To query during capture, use a managed session:

```sh
ciallogcat-cli start --serial DEVICE_SERIAL --session-dir ./capture-session --duration-secs 900 --max-bytes 134217728 --tail 1
ciallogcat-cli query --session-dir ./capture-session --query iframe-login --all --format text
ciallogcat-cli stop --session-dir ./capture-session
```

For `capture --output capture.jsonl`, wait until capture has finalized the file before using `query --file capture.jsonl`.

## Downloads and compatibility

The release provides Linux x86_64 CLI tar.gz, Windows x86_64 CLI ZIP and Ubuntu 24.04 amd64 CLI DEB packages, each with a SHA-256 file (six uploaded assets). ADB is installed separately. Archive, query response and cursor formats are unchanged.

This CLI-only release does not replace the repository's Latest marker. Use the [v1.3.1 release page](https://github.com/IllyasvielEin/Ciallogcat/releases/tag/v1.3.1) for these downloads.

GitHub's automatic source archives contain the full repository, including GUI sources and intervening GUI changes. The shared Cargo package version is 1.3.1; this release does not publish GUI binaries. Existing public tags and assets are not replaced.
